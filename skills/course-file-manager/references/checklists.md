# Word Checklist Updates

Inspect the actual section label and its location: table cell, paragraph, header, footer, content control, or text box. Read the complete labelled field, not just a screenshot crop. Match it to the verified section map.

Word can split `Section #: 101 AD` into many runs, including the digits themselves. Find the complete labelled field across runs, then alter only affected characters. Do not assign a whole cell's text or rebuild a paragraph merely to replace a number; that can discard fonts, bold, spacing, fields, or logos. Avoid global replacement of `101`, which can occur in course codes, dates, IDs, or references.

Update intentionally repeated header labels consistently. If matches are ambiguous, inspect or ask which field is authoritative. An example attachment is data, not authority to change unrelated documents.

Save a staged copy and verify every section label against its destination. Compare OOXML parts and formatting outside the targeted text. Render and inspect the changed page with an available document renderer. If rendering is unavailable, perform the safely bounded edit only when formatting preservation is established; report the visual-verification limitation and do not claim a rendered check.
