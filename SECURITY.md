# Reporting a privacy or security concern

Do not post student data, grades, attendance, account credentials, or live system screenshots in issues or pull requests.

If GitHub's private vulnerability reporting is available for this repository, use **Security > Report a vulnerability** with a minimal fictional reproduction. If that option is unavailable, open a public issue containing only a general description and ask the maintainer for a private reporting channel. Do not include the sensitive material in the public issue.

For ordinary parsing bugs, use fictional CSV/XLSX fixtures or the synthetic test generator. This toolkit does not provide institutional authorization, account access, or a student-data storage service.
